# E-Commerce Sales & Customer Analytics

## Project Overview
This project focuses on managing e-commerce data and analyzing sales information using SQL. It demonstrates relational database concepts and SQL queries for extracting useful business insights.

## Database Components
- **Products:** Stores product-related information.
- **Customers:** Stores customer details.
- **Sales:** Stores sales transaction information.

## Key Features
- Relational database design
- Primary and foreign key relationships
- Sales and revenue analysis
- Product and customer analysis
- Category-wise and city-wise reporting
- Monthly sales analysis

## Technologies Used
- SQL
- Relational Database Management Systems (RDBMS)

## Project Files
- `E_commerce database.sql` — SQL database script
- `E_commerce database.zip` — Original project archive

## Learning Outcomes
- Understanding relational database design
- Writing SQL queries for data analysis
- Using aggregate functions and grouping
- Analyzing sales data for business insights
